## What I'm building

### [Task Force Merlin](https://taskforcemerlin.com) · AI, software engineering & simulation

A passion project turned into a connected engineering ecosystem for an Arma Reforger community.

| System | The problem it solves |
| --- | --- |
| **Merlin** | Turning operational evidence into useful intelligence and informed decisions |
| **ARC Commander** | Coordinating autonomous AI behaviour across dynamic game worlds |
| **HQC** | Giving people a single place to plan missions, manage operations and understand what's happening |
| **Evidence pipeline** | Connecting game events, service records and reporting into a consistent view of reality |

The interesting part isn't any one component. It's making the whole thing work together: **game events → evidence → decisions → actions → verification**.

The implementation lives in private repositories, but the challenges are the ones I enjoy most: system boundaries, reliable data, automation, useful UX and making complicated software feel simple.

### How I approach engineering

- **Solve the actual problem.** Don't add layers just because we can.
- **Make systems observable.** A confident answer needs evidence.
- **Build for change.** Clear boundaries beat clever shortcuts.
- **Ship, learn, improve.** Working software matters more than diagrams that never leave the drawing board.
